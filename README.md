1  # ⚡ FLUX.1 Schnell Lightweight Generator
 2  
 3  A minimal Python script to generate photorealistic AI images in under 2 seconds using Black Forest Labs' **FLUX.1-schnell** model.
 4  
 5  ## 🚀 Features
 6  - Ultra-fast generation (optimized for 4 inference steps)
 7  - Accurate text rendering inside images
 8  - Fully open-source and free to run
 9  
10  ## 🛠️ Quick Setup
11  
12  1. **Clone the repository:**
13     ```bash
14    git clone https://github.com/sohailsiyam/flux-fast-generator.git
15    cd flux-fast-generator
16     ```
17  
18  2. **Install requirements:**
19     ```bash
20     pip install -r requirements.txt
21     ```
22  
23  3. **Run the script:**
24     ```bash
25     python generate.py
26     ```
27
